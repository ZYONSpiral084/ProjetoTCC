## Resumo / Summary / 概要
**PT-BR:** SPIRAL é uma plataforma informativa e educativa sobre o Transtorno do Déficit de Atenção com Hiperatividade (TDAH). Fornece textos, vídeos e referências acadêmicas com interface responsiva (PHP + Bootstrap).  
**EN:** SPIRAL is an informational educational platform about Attention Deficit Hyperactivity Disorder (ADHD). It delivers articles, videos and academic references with a responsive UI (PHP + Bootstrap).  
**中文:** SPIRAL 是一个关于注意力缺陷多动症（ADHD/TDAH）的教育性信息平台，提供文章、视频与学术参考，采用响应式界面（PHP + Bootstrap）。

> **Nota / Note / 注意：** Conteúdo informativo — **não substitui** avaliação ou diagnóstico clínico.
